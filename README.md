# Murmuration · 2D Boids

使用 Bevy 0.20 编写的鸟群行为模拟。默认 1000 只鸟，支持分离、对齐、聚合、游隼切割与驱散、右键吸引跟随，以及实时参数调节。

## 启动

```sh
cargo run
```

首次运行需要编译 Bevy 和界面依赖。需要图形桌面及支持的 GPU 驱动。

## 操作

| 操作                          | 效果                                                                   |
| ----------------------------- | ---------------------------------------------------------------------- |
| 移动鼠标                      | 鼠标扮演游隼，沿移动路径切开并驱散鸟群；快速移动产生更强的威胁         |
| 按住右键拖动                  | 鸟群跟随鼠标；松开恢复游隼模式，切换时清除待处理切割路径和逃逸反应     |
| Mouse influence / `M`         | 开启或关闭全部鼠标影响；关闭后鸟群继续自主飞行、聚合                   |
| Pause / Resume / 空格         | 暂停或继续，暂停时冻结鸟的位置、轨迹、翼展与逃逸计时                   |
| Reset flock / `R`             | 重新生成鸟群，保留当前参数和暂停状态                                   |
| Defaults                      | 恢复默认模拟和外观参数，保留暂停状态                                   |
| `1` / Fly                     | 正常游隼与右键跟随操作                                                 |
| `2` / Inspect                 | 点击附近的鸟进行观察，点击空白处清除选择；此工具禁用鼠标飞行影响       |
| `3` / Obstacles               | 点击空白处放置圆形障碍，点击圆形选中并拖动；`Delete` 删除选中障碍      |
| Tight / Loose / Evasive       | 切换行为预设，保留鸟数和鼠标开关，可继续手动调整                       |
| Save settings / Load settings | 保存或加载工作目录中的 `boids-settings.json`；启动时自动恢复已保存参数 |
| 各参数分组的 Reset            | 只恢复这一组的默认参数                                                 |
| 面板标题                      | 拖动面板；点击折叠箭头收起面板                                         |

观察和障碍物工具在暂停时也能使用。选鸟后切回 Fly，可以继续观察游隼造成的逃逸响应；选择保留到清除、鸟被删除或重置鸟群。

障碍物提前影响转向和速度，扫掠碰撞检查避免单步穿越。圆形之间必须保留空间；新增或移动障碍覆盖鸟的位置时，会将这些鸟移到圆外并重置其轨迹。重置鸟群保留障碍物，清空场景使用 Clear obstacles。缩小窗口时仍保留障碍物的世界位置，超出窗口的部分暂时不可见；修正鸟的位置时也会避开障碍。障碍物和观察工具状态不包含在参数文件中。

参数文件保存 SimulationSettings 和 Appearance 中的全部设置，不保存鸟的位置或播放状态。加载先完整解析、校验范围，失败时保留当前参数并显示原因；保存先写临时文件，再替换目标。预设只改变模拟参数，保留鸟数、鼠标开关和外观；工具状态不随预设切换。

面板支持滚动和折叠分组，在小窗口中也能访问全部参数。编辑数值时，快捷键不会抢占键盘输入。

面板上的鼠标移动不会影响鸟群。从面板开始的拖动会一直捕获到松键；从场景开始的拖动经过面板时暂停影响，返回场景后继续。鼠标离开窗口或窗口失焦时清除鼠标作用与待处理路径。

## 实时调节项

| 分组                  | 参数                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------ |
| 鸟群数量              | 100–5000，步长 100，增减时保留已有鸟的位置和轨迹                                           |
| Flock behavior        | 分离、对齐、聚合、整体重聚强度；感知半径；分离距离；全部邻居 / 最近邻模式；最近邻数量 1–16 |
| Flight                | 巡航速度、转向率上限、个体差异、X/Y 风向作用                                               |
| Falcon and attraction | 威胁半径、驱散强度、预测时间、逃逸记忆时长、吸引强度                                       |
| Appearance            | 残影时长 0–2 秒（0 为关闭）、透明度、线宽、鸟形大小、翼展动画、鼠标作用范围显示            |
| Observation           | 逃逸着色、行为指标开关、选中鸟与邻居信息、规则箭头图例                                     |
| Obstacles             | 新障碍半径 20–100、删除选中、清空障碍                                                      |
| Performance details   | 网格、转向、运动更新的平均耗时，模拟 p95，CPU 绘制数据生成耗时                             |

滑块上的提示说明参数效果。Tight 使用较强对齐和聚合，Loose 使用较弱聚合和更大间距，Evasive 使用较高速度、较强威胁和较长逃逸记忆。确定性 300 只鸟、10 秒自然飞行检查中，Tight 平均最近邻距离约 9.02，Loose 约 22.24。

观察箭头显示分离（红）、对齐（蓝）、聚合（绿）、逃逸（橙）的加权贡献，位于最终转向限制之前，显示长度上限 100。青色标记参与对齐与聚合的邻居；近距离分离仍检查红圈内所有邻居。行为指标按需每 0.5 秒更新：对齐度是单位飞行方向的平均向量长度，最近邻距离搜索包含感知范围外的鸟。指标计算耗时单独显示，关闭时跳过计算。

参数即时生效。部分组合会改变群体形态：关闭聚合和整体重聚会减弱重新汇合；增大感知半径和鸟数会增加计算量。低转向率、高巡航速度或接近边缘时，鸟会根据转弯空间减速。风向参数持续影响转向，不直接平移鸟的位置。

## 模拟与绘制

- 60 Hz 固定模拟步长，绘制时插值位置和方向；新增与重置的鸟使用当前巡航速度出生。
- 鼠标输入保存带时长的移动区间，按固定模拟步插值并消费路径。30、60、144 FPS 的同一直线输入回放已验证一致；采样间的曲线路径仍只能由输入端点近似。
- 空间网格搜索附近九个格子；网格尺寸随感知半径变化。近距离分离始终检查所有候选鸟，最近邻限制只影响对齐与聚合。
- 使用 Bevy 任务池并行计算转向，再统一更新鸟的位置，避免计算顺序影响行为。
- 转向与巡航速度分别控制，加入少量固定个体差异；边界预测提前转向和减速。
- 游隼作用覆盖移动路径和预测前进方向，并留下逐渐衰减的逃逸反应；吸引模式和关闭开关立即覆盖逃逸反应。
- 窗口缩放时仅移回场外鸟并重置其轨迹，普通飞行不重置轨迹或瞬间翻转速度。
- 轨迹使用每只鸟 64 个位置的环形数组，30 Hz 采样。绘制跳过尚未到达的最新采样点，颜色每帧预计算；残影关闭时跳过轨迹绘制。

## 代码结构与依赖

| 文件                                    | 职责                                   |
| --------------------------------------- | -------------------------------------- |
| `src/main.rs`                           | 应用、资源与系统调度                   |

| `src/boids.rs`                          | 鸟的飞行状态、群体规则、速度和转向更新 |

| `src/mouse.rs`                          | 游隼路径、速度、预测与驱散场           |
| `src/input.rs`                          | 场景输入、界面拖动捕获与快捷键         |
| `src/runtime.rs`                        | 初始化、暂停、重置、默认参数和模拟系统 |
| `src/render.rs`                         | 鸟形、翼展、运动残影与作用范围绘制     |
| `src/ui.rs`                             | 参数面板与状态显示                     |
| `src/interaction.rs`                    | 飞行、观察、障碍物工具与场景拖动       |
| `src/obstacles.rs`                      | 圆形场景、绕行、减速与扫掠碰撞         |
| `src/observation.rs`                    | 选鸟观察与按需行为指标                 |
| `src/presets.rs` / `src/preferences.rs` | 行为预设与参数文件读写、范围校验       |

界面采用 `bevy_egui` 0.43.1，与 Bevy 0.20 配套，复用滑块、复选框、折叠区域、滚动和数值编辑。仅启用 `render`、`default_fonts`，无需剪贴板或浏览器集成。参数文件使用 [Serde](https://serde.rs/derive.html) 和 [serde_json](https://docs.rs/serde_json/) 的派生序列化与 JSON 读写，复用现有依赖树中的版本。数学、并行任务和批量绘制继续使用 Bevy 提供的能力。

## 检查与性能测量

```sh
cargo test
cargo clippy --all-targets -- -D warnings
cargo run -- --profile
cargo run -- --profile-graphics
```

测试覆盖群体行为、参数生效、空间搜索、边界与窗口缩放、持续飞行、重聚、鼠标切割和模式切换、逃逸衰减、暂停与重置、拖动捕获、轨迹衔接，以及直接点击界面按钮和滑块。

`--profile` 无需图形桌面：在 1280×800 场地测量 1000、3000、5000 只鸟的自然飞行、游隼切割、中央吸引、三个圆形障碍场景；另测 5000 只鸟、140 感知半径的密集吸引。每种场景模拟 8 秒，前 3 秒预热；输出最后 120 步的平均分阶段耗时和 p95，单位为毫秒。结果只包含 CPU 模拟，不包含绘制或 GPU 时间，也不是帧率。

`--profile-graphics` 需要可见的图形窗口。自动比较 5000 只鸟、140 感知半径、中央吸引下的两秒残影与关闭残影；两组从同一初始分布开始，每组运行 6 秒，前 3 秒预热，输出后 3 秒的完整帧平均时间、p95 和实际场地尺寸，然后退出。测量时保持窗口可见、尺寸不变。默认呈现方式包含垂直同步等待。

面板中的 Frame 统计最近 120 个真实帧间隔，暂停时仍更新，包含模拟、渲染与呈现等待。`CPU draw` 是绘制数据生成耗时的平滑值，不包含 GPU 时间。行为指标有独立的计算耗时显示。
